# ps-study

자바스크립트를 공부하며 유용한 기능들을 직접 구현해보고, 프로그래머스 코딩테스트 문제를 풀며 기록하는 개인 저장소입니다.
앞으로는 Java 풀이도 이 저장소에 함께 추가할 예정입니다.
이곳의 모든 코드는 상세 설명과 함께 *노션(Notion)*에 실시간으로 아카이빙되고 있습니다.

---

## 📁 폴더 구조 안내

* **`JS_기능구현/`** - 웹사이트에서 쓰이는 유용한 동적 기능 구현
  * `To_Do_List/` : 할 일 목록 기능
  * `드래그 앤 드롭/` : 마우스로 요소를 끌어서 놓는 드래그 앤 드롭 기능
  * `비밀번호 강도확인/` : 입력한 비밀번호의 강도를 확인하는 기능
  * `상자이동/` : 상자를 이동시키는 기능

* **`programmers/`** - 프로그래머스 코딩테스트 문제 풀이
  * `js/lv0/` : JavaScript로 푼 레벨 0 문제
  * `java/lv1/` : Java로 풀 예정인 레벨 1 문제 (준비 중)
